# Файлы и каталоги

Сервис хранит данные в трёх местах: состояние и история — в `~/Library/Application Support/pr-reviewer/`, git-копии — в `~/.pr-reviewer/`, журнал — в `~/Library/Logs/pr-reviewer/`. Окно ничего не хранит в своих файлах: оно читает файлы сервиса и вызывает команды CLI. Личные настройки окна (уведомления, тема, фильтры, свёрнутые секции) лежат в UserDefaults приложения.

`./uninstall.sh` удаляет агентов launchd, приложение и `bin/`, а данные оставляет. `./uninstall.sh --purge` удаляет ещё `~/Library/Application Support/pr-reviewer/` и журналы. `~/.pr-reviewer/` не удаляет ни один из вариантов — его можно удалить вручную.

## ~/Library/Application Support/pr-reviewer/

### Сервис

| Путь | Что это | Можно удалить? |
|---|---|---|
| `state.json` | Память сервиса: какие головы PR каждая модель уже проверила, отпечатки диффов, на какие треды модели ответили, опубликованные замечания (для исходов), проверки своих тредов, кто ходит первым, ошибки подряд, разобранные памятью комментарии | **Нет.** Без него сервис заново отревьюит все открытые PR, а замечания до этого момента выпадут из статистики исходов |
| `status.json` | Что идёт сейчас, последние 30 ревью, последний запуск и ошибка. Его читают окно и `status` | Да, создастся заново |
| `paused` | Есть файл — фоновое ревью на паузе | Удалить = `resume` |
| `worker.pid` | Лок прохода: pid идущего воркера. Лок от мёртвого процесса не мешает | Не нужно |
| `heartbeat` | Пульс прохода: обновляется раз в 30 секунд. Окно считает проход зависшим через 15 минут без пульса | Не нужно |
| `run-requested` | Метка «Запустить сейчас» для следующего пробуждения launchd | Да |
| `queue/` | Явные заявки на ревью: файл на пару «PR и модель» | Удалить = снять заявки |
| `prs/<slug>.json` | Снимок открытых PR для окна: треды, отставание ветки от базы, последние комментарии людей | Да, `sync` пересоздаст |
| `tmp/` | Рабочая папка запусков моделей | Да, когда ничего не идёт |

### Статистика и кэши

| Путь | Что это | Можно удалить? |
|---|---|---|
| `stats.jsonl` | Каждый запуск ревью: модель, роль, замечания по уровням, вердикты, цена, длительность | Пропадёт статистика ревью и цена |
| `outcomes.jsonl` | Исходы опубликованных замечаний: исправлено, отклонено, отложено | Пропадут доли исправленных и отклонённых |
| `skips.jsonl` | Пропущенные раунды ревью (rebase без изменений, пустой дифф, только исключённые файлы) | Пропадёт раздел «Экономия» |
| `spend.jsonl` | Траты служебных запусков: память и бэклог | Пропадут эти траты в «Стоимости» |
| `limits.json` | Остатки лимитов подписок | Да, обновится |
| `cursor-models.json` | Модели Cursor для настроек окна | Да, обновится |

Поля журналов — в [stats.md](stats.md).

### Режимы

| Путь | Что это |
|---|---|
| `fixes/queue/`, `fixes/state/`, `fixes/resume/`, `fixes/worker.pid`, `fixes/tmp/` | Доработка: очередь, состояние и отчёт по каждому PR, данные для продолжения с сохранённой ветки, лок обработчика |
| `fixes.jsonl` | История доработок и rebase с ценой |
| `arch/queue/`, `arch/state/`, `arch/worker.pid`, `arch/tmp/` | Архитектурное ревью: очередь, последний отчёт по каждому PR, лок |
| `arch.jsonl` | История архитектурных ревью с вердиктом и ценой |
| `qa/queue/`, `qa/state/`, `qa/runs/`, `qa/worker.pid`, `qa/tmp/` | Тестирование: очередь, план и отчёт по каждому PR, файлы прогонов (`qa/runs/<repo>__<pr>/<время>/` — тесты, видео, скриншоты) |
| `qa.jsonl` | История планов и прогонов с ценой |
| `backlog.json` | Бэклог: проблемы вне скоупа PR и их статус |
| `backlog-scan.json` | Какие треды влитых PR уже разобраны задачей «Собрать из истории PR» |
| `backlog-job.json` | Ход и итог последней задачи бэклога (сбор или разбор) |
| `memory/<slug>.json` | Правила памяти репозитория. Можно править руками; если файл станет невалидным, сервис перестанет его перезаписывать и покажет баннер |
| `memory/<slug>.review.json` | Сохранённый план разбора памяти |
| `memory/<slug>.history.jsonl` | Журнал изменений памяти |
| `memory/backups/` | Копии памяти перед применением разбора — для отката |

Подробнее: [fix.md](fix.md), [arch.md](arch.md), [qa.md](qa.md), [backlog.md](backlog.md), [memory.md](memory.md).

## ~/.pr-reviewer/

Только git-копии. Путь нарочно без пробелов: git-хуки репозиториев (например, husky `commitlint --edit ${1}`) часто не берут путь в кавычки.

| Путь | Что это | Можно удалить? |
|---|---|---|
| `repos/<slug>` | Служебный клон: ревью переключает его на голову PR в detached-режиме. В `.pr-review/` внутри — входные файлы для модели на время запуска | Да, когда ничего не идёт: скачается заново (с `source`, если он задан). Удаляйте вместе с `<slug>` во всех `*-workspaces/`: это worktree клона, без него они ломаются |
| `fix-workspaces/<slug>` | Worktree служебного клона для доработки, со своим `node_modules`. Здесь же локальные ветки `backup/…` и `pr-reviewer-fix/…` | Да, но пропадут сохранённые правки неудачных доработок |
| `arch-workspaces/<slug>` | Worktree для архитектурного ревью | Да |
| `qa-workspaces/<slug>` | Worktree фронтенда и бэкенда для тестирования, у фронтенда — свой `node_modules` | Да, первая сборка потом будет дольше |
| `backlog-workspaces/<slug>` | Worktree основной ветки для разбора бэклога | Да |
| `cursor-home/` | Отдельная домашняя папка Cursor CLI: без неё он подхватывает ваши хуки, правила и MCP из `~/.cursor` и `~/.claude` | Да, создастся заново |

## Журналы

| Путь | Что это |
|---|---|
| `~/Library/Logs/pr-reviewer/worker.log` | Журнал сервиса и команд. Ошибки — с меткой `ERROR`. Его же показывает вкладка «Журнал» |
| `~/Library/Logs/pr-reviewer/worker.log.1` | Прошлый журнал: в начале прохода журнал больше 5 МБ переименовывается |
| `~/Library/Logs/pr-reviewer/launchd.out.log`, `launchd.err.log` | Вывод самого launchd — смотреть, если воркер не стартует вовсе |

## Установка

| Путь | Что это |
|---|---|
| `config.json` в папке проекта | Настройки, см. [config.md](config.md) |
| `bin/pr-reviewer` | Обёртка CLI, которую генерирует `install.sh`: в ней зашиты пути к `node`, `claude`, `codex`, `cursor-agent` |
| `~/Library/LaunchAgents/com.avoronin.pr-reviewer.plist` | Агент launchd воркера: будит `run --scheduled` раз в минуту |
| `~/Library/LaunchAgents/com.avoronin.pr-reviewer.menubar.plist` | Агент launchd приложения: запускает его при входе и перезапускает после сбоя |
| `~/Applications/PR Reviewer.app` | Приложение в строке меню; собирается `install.sh` из `menubar/*.swift` |

## Keychain

| Запись | Что в ней |
|---|---|
| `pr-reviewer-bitbucket`, аккаунт — `bitbucket.email` | API-токен Atlassian |
| `pr-reviewer-claude` | Токен `claude setup-token` |
| `pr-reviewer-cursor` | API-ключ Cursor (если Cursor используется) |
| `cursor-access-token` | Токен входа самого Cursor CLI; сервис только читает его, чтобы узнать остаток лимита |

Имена первых трёх записей задаются полями `keychainService` в [config.md](config.md). Как их создать — в [install.md](install.md).
