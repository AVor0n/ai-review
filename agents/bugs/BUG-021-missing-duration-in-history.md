# BUG-021: нет `durationSec` у плана тестирования и у доработки «Открытых замечаний нет»

- **Статус:** отложен
- **Серьёзность:** S4
- **Компонент:** CLI (`src/qa.mjs`, `src/fix.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** техпод при написании docs/, подтверждено qa по коду

## Описание

В записи плана в `qa.jsonl` нет `durationSec`, а у прогона есть. У доработки, которая закончилась на «Открытых замечаний нет», `runFix` возвращает результат без `durationSec`, и в `fixes.jsonl` поле пустое. Длительность этих запусков пропадает из истории и статистики.

## Предполагаемое место в коде

- `src/qa.mjs:734` — запись плана без `durationSec`.
- `src/fix.mjs:226` — ранний `return` без `durationSec` (у остальных исходов его ставит `finish`).
