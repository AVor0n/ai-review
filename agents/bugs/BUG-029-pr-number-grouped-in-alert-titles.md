# BUG-029: номер PR в заголовках подтверждений с пробелом — «#2 058»

- **Статус:** закрыт
- **Серьёзность:** S4
- **Компонент:** окно (`menubar/OverviewView.swift`)
- **Заведён:** 2026-10-30, qa
- **Источник:** найдено qa при проверке окна на отдельной копии

## Описание

Заголовок подтверждения доработки — «Доработать #2 058 по замечаниям?». Номер PR разбит пробелом, как число с разрядами. В строке PR, в листах и в уведомлениях номер пишется без пробела: «#2058».

Причина, по коду. Строковый литерал в `.alert(...)` SwiftUI принимает как `LocalizedStringKey`. Число в нём форматируется по локали ru_RU с разделителем разрядов. Задеты все PR с номером от 1000, то есть все PR сейчас.

## Окружение

- Код 446b810, отдельная копия окна (данные — копия).

## Шаги воспроизведения

1. «Обзор» → волшебная палочка у PR с открытыми замечаниями (например, backend#2058).
2. Прочитать заголовок подтверждения. Отменить.

## Фактический результат

«Доработать #2 058 по замечаниям?». По коду так же будут выглядеть «Сделать rebase #2 058 на …?» и «Архитектурное ревью #2 062?».

## Ожидаемый результат

«Доработать #2058 по замечаниям?», как везде в окне.

## Логи и доказательства

Скриншот копии окна, увеличенный заголовок: «Доработать #2 058 по замечаниям?».

- `menubar/OverviewView.swift:34` — заголовки доработки и rebase.
- `menubar/OverviewView.swift:51` — заголовок архитектурного ревью.
- Остальные места с номером PR — `Text(verbatim:)` или обычные `String`, их не задевает.
