# BUG-033: таймаут одного вызова модели убивает все вызовы моделей в сервисе

- **Статус:** закрыт
- **Серьёзность:** S2
- **Компонент:** сервис (`src/agents.mjs`, `runProcess`)
- **Заведён:** 2026-11-17, qa
- **Источник:** найдено qa при повторной проверке B-24 (8bf8c2c), раздел «Таймауты»

## Описание

Когда вызов модели не укладывается в свой таймаут, `runProcess` вызывает `killAgents()`. Эта функция шлёт SIGTERM группам **всех** запущенных процессов моделей, а не только зависшего. Сервис ревьюит репозитории параллельно (`parallelRepos`, по умолчанию 3) в одном процессе. Поэтому таймаут в одной дорожке обрывает ревью в других: модели получают код выхода `null`, ревью падает с ошибкой, лимиты на него уже потрачены.

Ошибка была с первого импорта, но раньше таймауты стояли только у ревью и были длинными. В B-24 (8bf8c2c) у разметки PR перед ревью таймаут 2 мин. Разметка идёт перед каждой новой головой, так что ошибка стала вероятной. Код B-24 уже работает на живой машине: сервис запускается из рабочей копии.

## Шаги воспроизведения

1. Копия из 8bf8c2c, вместо `claude` в `PATH` заглушка, которая спит 40 с.
2. В одном процессе одновременно два `runStructured`: «ревью» с `timeoutMinutes: 5` и «разметка» с `timeoutMinutes: 0.25`.

## Фактический результат

```
разметка (15 с): ошибка через 15 с — claude: превышен таймаут 0 мин
ревью (5 мин): ошибка через 15 с — claude завершился с кодом null:
```

## Ожидаемый результат

По таймауту убивается только группа процесса, который не уложился (`process.kill(-child.pid, 'SIGTERM')`). Остальные вызовы работают дальше. `killAgents()` остаётся для остановки всего сервиса и для отмены задач.

## Попутно

Текст ошибки «превышен таймаут 0 мин» при таймауте меньше минуты: `Math.round(timeoutMs / 60000)`. У разметки таймаут 2 мин, там текст верный.

## История

- 2026-11-17 — пользователь решил чинить. qa: `17a334b`, по таймауту убивается только группа своего процесса (`killGroup`), `killAgents()` не изменился. Тот же опыт на заглушке: «разметка» упала через 15 с, «ревью» ответило через 40 с. `npm test` 34/34. Сервис запускается из рабочей копии, поэтому правка действует со следующего запуска, установка не нужна.
