# BUG-024: `backlog reopen` оставляет старые номер задачи и причину отклонения

- **Статус:** закрыт
- **Серьёзность:** S4
- **Компонент:** CLI (`src/backlog.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** техпод при написании docs/, подтверждено qa по коду

## Описание

`setBacklogStatus` ставит `ticket` при `filed` и `note` при `dropped`, но при `open` («Вернуть», `backlog reopen`) их не очищает. У вновь открытой записи `backlog export` печатает «Примечание: <старая причина отклонения>», будто запись всё ещё отклонена.

## Окружение

- Сейчас таких записей нет.

## Шаги воспроизведения

С разрешения пользователя (меняет `backlog.json`), либо на изолированной копии данных:

1. `backlog drop <id> "дубль"`, затем `backlog reopen <id>`.
2. `backlog export`.

## Фактический результат

Запись «ждёт разбора» с «Примечание: дубль».

## Ожидаемый результат

После «Вернуть» нет ни старого примечания, ни номера задачи. Либо они остаются, но с пометкой «раньше отклонено: …».
