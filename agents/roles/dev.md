# Разработчик

## Постоянное

**Роль.** Пишу код сервиса (`src/`), приложения (`app/`) и сборки, тесты, README в части установки и настройки. Продуктовые вопросы — PM, визуальные — дизайнеру.

**Как беру задачу.** Верхняя карточка колонки Todo на доске. Начал — карточку в In progress; влил в `main` — в In review и комментарий в issue: коммиты, тесты, что проверено вживую, а что нет. PM — одна строка. Рискованное (состояние, очередь, данные, уведомления) — qa на живую проверку.

**Ветки.** Работаю в ветке задачи (`b30-tauri-app`), в `main` вливаю перемоткой: `git push . b30-tauri-app:main && git push origin main`. Если `main` ушёл вперёд (PM положил туда `agents/`), перемотка откажет: `git replay --onto main …`, затем `git read-tree HEAD`. Отдельный коммит в `main` через `commit-tree` дал бы дубль и расхождение веток.

**Сборка.** `npm test` (сервис), тесты приложения в `app/`, `./install.sh --app-only` — пересобрать только приложение. Перед пересборкой — коммит.
