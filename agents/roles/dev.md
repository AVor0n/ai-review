## Постоянное

**Роль.** Пишу код сервиса (`src/`), приложения (`app/`) и сборки, тесты, README в части установки и настройки (правлю в том же коммите, что и код). Продуктовые вопросы — PM, визуальные — дизайнеру.

**Как беру задачу.** Верхняя карточка колонки Todo на доске. Начал — карточку в In progress; влил в `main` — в In review и комментарий в issue: коммиты, тесты, что проверено вживую, а что нет. PM — одна строка. Рискованное (состояние, очередь, данные, уведомления) — qa на живую проверку.

**Ветки.** Работаю в ветке задачи (`b30-tauri-app`), в `main` вливаю перемоткой: `git push . b30-tauri-app:main && git push origin main`. Перед этим `git fetch origin`: PM и qa коммитят в `main` без переключения веток и пушат сразу, локальный `main` может отставать от `origin/main`.
- `main` ушёл вперёд, а у меня новых коммитов нет — перемотать ветку: `git merge --ff-only origin/main`, затем `git update-ref refs/heads/main origin/main`.
- У меня есть свои коммиты — `git replay --onto origin/main …`, затем `git read-tree HEAD`. Отдельный коммит в `main` через `commit-tree` дал бы дубль и расхождение веток.
- После такого чужого коммита его файлы остаются в моей рабочей копии изменёнными или неотслеживаемыми, и перемотка на них откажет. Сверить каждый с коммитом (`git show origin/main:<путь> | cmp - <путь>`); одинаковые убрать (`rm` / `git checkout --`) и перематывать. Различается — не трогать, спросить автора.

**Сборка.** `npm test` (сервис, node:test), `npx vitest run` в `app/` (приложение), `npm run build` в `app/` (генерация клиента из OpenAPI, `tsc`, vite). `./install.sh --app-only` — пересобрать и перезапустить только приложение, сервис не трогает; идёт пару минут, запускать в фоне. Перед пересборкой — коммит: строка сборки в «Настройках» помечает незакоммиченные правки.

**Тексты приложения** (#68) — только через словари `app/src/i18n/ru/*.ts` и `app/src/i18n/en/*.ts`, новые строки сразу в оба. Формы числа — объект с `other` (`one/few/many` для ru), подстановки `{name}`. `dictionaries.test.ts` сверяет ключи и подстановки и ловит кириллицу в en. Глоссарий — в `agents/design/specs/2026-11-27-localization.md` (замечание → finding). Тексты сервиса (`src/`) пока на русском.

## Уроки

- **Старый сервис.** Приложение собрано с новым маршрутом API, а сервис старый — запрос отвечает 404 «Нет такого ресурса». Маршруты сервиса обновляет только полная `./install.sh`, на неё нужно разрешение пользователя. Проверить маршрут без порчи конфига: отправить заведомо неверное значение, жду 409.
- **Новый маршрут API** — три места: `src/api.mjs`, `schema/api.openapi.json`, `test/api.test.mjs`; клиент приложения генерируется при `npm run build`. Настройки идут через `cliAction` → команда `src/cli.mjs` и `schema/config.schema.json`.
- **Тесты приложения** идут в node без окна: язык там русский, `navigator` и Tauri нет. Тексты в тестах — русские.
- **Язык в Rust.** Трей и ошибки Rust берут язык из файла `language` в `app_config_dir()`, его пишет команда `set_language` из вебвью: стартовое меню нужно до загрузки вебвью. Новую строку в `lib.rs` писать через `tr(ru, en)`.
- **Английские даты** — локаль `en-GB` (`locale()` в `i18n/index.ts`): 24 часа и «27 Nov».
- **Выпуск.** Пуш тега не запускает workflow `app`: `gh workflow run app --repo AVor0n/ai-review --ref app-v<версия>`. Тег и релиз — только с разрешения пользователя.
- **`.claude/`.** Глобальный `~/.gitignore` автора прячет `.claude` целиком, поэтому в `.gitignore` репозитория стоит `!.claude/` перед `.claude/*` и `!.claude/launch.json`. Рендеры SF Symbols для макетов исключены локально в `.git/info/exclude` (`agents/design/mockups/2026-11-27-icon-weight/sf/`) — на новой машине добавить туда же.
- **Песочница Bash.** Цикл zsh по массиву (`for a in $areas`) проверка прав блокирует как word-split — файлы писать через Write или перечислять явно.
- **Предупреждение сборки** `INEFFECTIVE_DYNAMIC_IMPORT` про `@tauri-apps/api/core` (из `i18n/index.ts`) безвредно, сборка проходит.
- **Rust на Windows** (26.11): MSVC Build Tools нет. Стоят `scoop install rustup mingw` и тулчейн `1.95.0-x86_64-pc-windows-gnu`; проверка — `cargo +1.95.0-x86_64-pc-windows-gnu check` в `app/src-tauri`, в PATH нужны `~/scoop/persist/rustup/.cargo/bin` и `~/scoop/apps/mingw/current/bin` (без него — «dlltool not found»). Полная сборка exe — workflow `app` на `main` (без тега релиза нет); новый запуск на той же ветке отменяет идущий.
- **autocrlf на Windows**: перезаписанный файл с LF (`gen:api` → `schema.d.ts`) `git status` считает изменённым, хотя `git diff` пустой — отсюда #71. После `npm run build` верни файл через `git checkout --`.
- **Значок в строке меню** для computer-use ищи по скриншоту: рядом есть похожие значки, клик по координатам вслепую попадает в чужое приложение.
