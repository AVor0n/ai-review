Поповер в приложении Tauri

одобрено 26.11.2026 25.11.2026 · дизайнер · задача B-30

Поповер переносится из SwiftUI в веб без изменений: те же сегменты, строка статуса, баннеры, секции репозиториев и строки PR. Вёрстка на этой странице — настоящий HTML/CSS на токенах agents/design/web/tokens.css и компонентах components.css, dev берёт её как есть. На macOS и Windows отличается только рамка: где поповер стоит, есть ли стрелка, как выглядит значок в трее. Всё остальное одинаковое.

Что нового по сравнению с окном SwiftUI. (1) Баннер «Сервис не запущен»: в SwiftUI его не было, потому что окно читало файлы само. (2) Иконки интерфейса — Phosphor вместо SF Symbols: SF Symbols по лицензии Apple можно использовать только на её платформах. (3) Текст баннера токена без слова «Keychain»: на Windows секреты хранятся не там. Остальное — паритет.
Изменение 26.11 (Q49, #52). Сегментов четыре: «Журнал» стал листом в «Настройках», см. макет журнала. Кнопка «Журнал» в баннерах открывает «Настройки» с листом журнала.

3. Состояния шапки

Показана только верхняя часть поповера. Все состояния, кроме первого, — паритет с SwiftUI.

Новое: сервис не отвечает (macOS; на Windows — другой текст, см. ниже)

Баннер появляется, если API не ответил дважды подряд (около 5 с), чтобы не мигать при запуске. Приложение само пробует подключиться снова; «Проверить снова» — попытка сразу. Если связь пропала, когда данные уже были, список PR остаётся на месте, а баннер встаёт первым. На Windows текст «Нет ответа от сервиса в WSL (127.0.0.1:8765). Откройте терминал Ubuntu — сервис запускается вместе с WSL. Если он не поднялся, выполните в PowerShell команду ниже», команда — wsl systemctl --user restart pr-reviewer-api. Её dev проверит на Windows.

5. Значок в трее

На Mac — как сейчас: шаблонное изображение, систему сама красит его под строку меню; справа число PR без ревью на текущем коммите. На Windows значок не перекрашивается системой, поэтому приложение выбирает белый или чёрный по теме панели задач. Текста рядом со значком на Windows не бывает, число рисуется бейджем в углу значка.

6. Экраны, которые ещё не перенесены

Решение PM: все пять сегментов на месте с первой поставки. Неперенесённый экран и кнопки, которые ведут на него, открывают заглушку. На Mac она отправляет в старое окно. На Windows старого окна нет, поэтому заглушка даёт команды для командной строки WSL, у каждой — кнопка «Скопировать».

macOS: вкладка «Бэклог»

Windows: «Обновить…» в баннере токена Bitbucket

Windows: вкладка «Настройки», тёмная тема
