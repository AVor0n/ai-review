## Зачем

Пользователь заметил, что значки трея стали угловатыми и грубыми, с толстыми линиями. Ему нужны аккуратные значки и на Mac, и на Windows.

Причина — трей рисовал общие значки Phosphor из строк PR. У них линия 1,5 pt и острые углы. У SF Symbols старого окна линия 1,03 pt (замер на картинке 36 px).

Для трея теперь свой набор значков. Значки строк PR не меняются.

## Как рисовать (`trayIcon.ts`)

- **Поле.** Значки `i-tray-*` занимают всё поле:
  - Mac — 36 px (18 pt × 2);
  - Windows — 16 px × масштаб экрана.

  Множитель 16/18 для них не нужен. Знак модели остаётся 13/16.
- **Толщина линии** — CSS-переменная `--tray-line`. Контуры значков используют `style="stroke-width: var(--tray-line, 1.15)"`. Переменную задаёт корневой `<svg>` в `symbolSvg`:
  - Mac — `style="--tray-line: 1"`, как у SF Symbols;
  - Windows — `--tray-line: 1.15` или без переменной: значение по умолчанию то же. При 16 px более тонкая линия бледнеет.
- **Цвет.** Линии нарисованы через `stroke="currentColor"`. При `color="#000"` из `symbolSvg` они закрашиваются, дальше `source-in` даёт цвет состояния, как раньше.
- **Маски.** У `i-tray-offline` и `i-tray-stall` внутри символа есть `<mask>` с id `m-tray-*`. При копировании `innerHTML` маски переносятся вместе со значком.

## Готово, когда

- В `tray.ts` все шесть состояний берут значки `i-tray-*`.
- На Mac в светлой и тёмной строке меню значки совпадают с разделом «Строка меню Mac» макета:
  - линия 1;
  - многоточие при проверке;
  - контурная пауза.

  Проверка — скриншот рядом с макетом.
- На Windows значки в 16, 20 и 24 px совпадают с разделом «Панель задач Windows»: линия 1,15, бейдж со счётчиком как раньше. На настоящем Windows ещё не проверено — проверить, когда будет машина.
