# Спецификация: официальные значки моделей

Дата: 30.10.2026, дизайнер. Одобрено пользователем 30.10.2026: брать официальные SVG; цвет Cursor оставить бирюзовым.

## Что меняется

Только форма значков. Цвета, размеры, состояния (приглушение «старого коммита», серый «нет ревью»), вращение во время ревью и места использования остаются прежними.

Где: `menubar/AgentIcons.swift:3-54` — фигуры `ClaudeMark`, `OpenAIMark`, `CursorMark`; их же использует значок строки меню `StatusMark` (`AgentIcons.swift:57-82`).

## Исходники

`agents/design/logos/` — обрезанные по знаку официальные SVG:

| Файл | Источник | viewBox |
|---|---|---|
| `claude-spark.svg` | медиа-архив Anthropic (anthropic.com/press-kit), «Claude Spark — Clay» | `0 0 94 94` |
| `openai-blossom.svg` | openai.com/brand, Blossom | `146.694 227.042 267.198 264.812` |

| `cursor-cube-tones.svg` | cursor.com/brand, многотонный куб — справочно, в приложении не используется | тот же |

В путях только абсолютные команды `M L H V C Z`. Правило заливки — по умолчанию в SVG (nonzero): вырезы (треугольник в кубе Cursor, внутренние фигуры Blossom) получаются за счёт направления обхода, `eoFill` не нужен.

## Как рисовать

- Каждая фигура — `Shape`, которая строит путь из SVG и масштабирует его в `rect` с сохранением пропорций (aspect fit, по центру): `scale = min(rect.width / vbW, rect.height / vbH)`, сдвиг на `-vbX, -vbY`.
- Все три знака — **заливкой**. Сейчас Codex и Cursor рисуются обводкой (`AgentMark`: `.stroke`, `StatusMark`: `filled = false`) — перевести на `.fill()` / `fillPath()`.
- Отступ внутри кадра оставить как сейчас (`StatusMark`: `insetBy(dx: 1.5, dy: 1.5)` в 16×16; в строке PR кадр 15×15).

## Цвета (без изменений)

- Claude — `Color(red: 0.85, green: 0.47, blue: 0.34)`, совпадает с фирменным Clay #D97757.
- Codex — графитовый / светло-серый (`AgentIcons.swift:100`). По правилам OpenAI Blossom нельзя раскрашивать — текущий нейтральный цвет им соответствует.
- Cursor — бирюзовый, как сейчас (`AgentIcons.swift:101`). Фирменный цвет Cursor чёрный, но бирюзовый нужен, чтобы отличать Cursor от Codex в строке PR и в сериях графиков статистики.
