## Что меняется по сравнению с SwiftUI

1. **Элементы управления.** Свои компоненты вместо системных переключателя, Picker и Stepper — одинаковые на Mac и Windows. `.select` и меню «…» открывают системное меню (`menu.popup()`): у выбранного пункта галочка, «Отключить…» красным.
2. **Листы и диалоги.** Листы — поверх поповера, как остальные. «Отключить <slug>?» — системный диалог: кнопка «Отключить и удалить клон» (опасная) и «Отмена», текст из SwiftUI.
3. **Токены без «Keychain»:**
   - статус «Нет в Keychain (<service>)» → «Не сохранён»;
   - в сноске «от даты сохранения в Keychain» → «от даты сохранения».
4. **Windows:**
   - «Показать служебную копию в Finder» → «Показать служебную копию в Проводнике», путь в WSL через `\\wsl.localhost\…`;
   - карточка запрета уведомлений: «Windows запретила уведомления PR Reviewer», кнопка «Открыть параметры уведомлений» — открывает `ms-settings:notifications`;
   - «Скопировать команду сохранения» копирует `pr-reviewer secret set <id>` для терминала Ubuntu, а не `security add-generic-password …`. `claude setup-token` — тоже в терминале Ubuntu;
   - «Открыть в VS Code» (config.json, файл памяти) открывает файл по пути в WSL. Без VS Code кнопки нет;
   - сохранение config.json — Ctrl+S вместо ⌘S;
   - в сноске «Общие» «macOS запретила уведомления — включите их в системных настройках.» → «Windows запретила уведомления — включите их в параметрах Windows.»
   - значение строки «Уведомления» «Запрещены в macOS» → «Запрещены в Windows».
5. Иконки — Phosphor. Заглушка «Настройки» и «Подключить…» из первой поставки убираются.

## Вкладка

Прокрутка, поля 16 по бокам, 8 сверху и снизу, между секциями 18. Секции:

**Общие.** Сноска — части через пробел:
- «Выключение фонового ревью прерывает идущее ревью.» или, на паузе, «Ручной запуск из обзора работает всегда.»;
- «Свои уведомления у <slugs>.» или фраза о запрете уведомлений.

| Строка | Элемент | Поведение |
|---|---|---|
| Тема | сегменты «Системная / Светлая / Тёмная», 90 px | ставит `data-theme` на `<html>`, «Системная» — без атрибута. Запоминается |
| Фоновое ревью | `.switch` | `pause` / `resume`. Подсказка из SwiftUI |
| Проверять каждые | значение «15 мин» и `.stepper` | шаги 1, 2, 5, 10, 15, 20, 30, 45, 60, 90, 120, 180, 240. На паузе строка `.settings-row--dim`, степпер неактивен, подсказка «Сначала включите фоновое ревью наверху» |
| Уведомления | `.settings-row--nav`: «N из 6» или «Выключены до 16:00» / «Запрещены в macOS» оранжевым | открывает лист. Значение пересчитывается раз в минуту |

**Подключённые репозитории.** Строка репозитория:
- `.icon-tile` с `i-repo-fill`: синяя, серая (`--gray`), если выключено фоновое ревью репозитория или всё фоновое ревью;
- «workspace/slug»;
- ниже remote и « · первый клон с <путь>» одной строкой с многоточием посередине;
- ошибка клона — красным до трёх строк;
- справа:
  - «Скачать» (`.link-button`), если клона нет; во время клона `.spinner` и «Скачивается…»;
  - `.memory-chip` — `i-brain` и число правил. С `--marked` и `--c`: `--red`, если файл памяти повреждён; `--accent`, если есть новые правила. Подсказки из SwiftUI. Клик открывает лист памяти;
  - `i-more` — меню: «Открыть в Bitbucket», «Память ревьюеров…», «Показать служебную копию в Finder» (без клона неактивен), разделитель, «Отключить…»;
  - `.switch` — пауза репозитория. На общей паузе 45 % и неактивен.

Разделители с отступом 52. Последняя строка — «Добавить репозиторий» (`.settings-row--add`, зелёный `i-plus-circle-fill`), открывает лист.

**Модели.** Строка модели:
- `.icon-tile--track` со знаком модели, `--off` (50 %), если модель выключена в фоне;
- имя;
- строка лимита `.limit`:
  - полоса 36×4: зелёная, `--yellow` ниже 40 %, `--orange` ниже 15 %;
  - текст «62% недели осталось · до 1 дек.», ниже 15 % — `.limit--low`;
  - нет данных — «лимит недоступен» или «лимит появится после ближайшего запуска», `.limit--none`;
  - устаревший лимит — серая полоса, `i-warning-fill` 9 px оранжевым, «4% на 14:10 · не обновляется»; после сброса — «лимит сброшен, остаток обновится» / «лимит сброшен · не обновляется». Правила свежести и подсказки — как в `AgentRow`;
- `.select` модели (160) и `.select` уровня reasoning (160). У Cursor вместо уровня — `.select-note` «в названии модели»;
- `.switch` фонового ревью модели.

Списки моделей и уровней — как в `AgentRow`:
- Claude — фиксированный список и «По умолчанию» + уровни;
- Codex — из кэша Codex CLI, с подменой неподдерживаемого уровня;
- Cursor — из `cursorModels`.

Модель из config.json, которой нет в списке, ставится первой. Сноска из SwiftUI.

**Дополнительно.** Строки `.settings-row--nav`:
- «Ветки для ревью» — шаблон моноширинным;
- «Исключения из диффа» — число;
- «Токены» — сводка:
  - «Cursor: истёк» красным;
  - «Bitbucket: 5 дн.» оранжевым;
  - иначе «до 1 дек.» или число;

**Строка сборки** `.build-info` — «Сборка <коммит 7> · 25.11 14:05», с годом, если не текущий. Для Tauri — версия и коммит сборки приложения. Если сборка с незакоммиченными правками — тег «правки не закоммичены» оранжевым. Подсказка — полная дата и коммит.

### Редактор config.json

- **Подсветка** — правила `JSONHighlighter`:

  | Что | Класс | Цвет |
  |---|---|---|
  | ключи | `.k` | основной |
  | строки и слова кроме true/false | `.s` | вторичный |
  | числа | `.n` | `--code-number` |
  | true/false | `.b` | `--code-boolean` |
  | скобки, двоеточия, запятые | `.p` | третичный |

- **Ввод.** Автозамена кавычек и тире, проверка орфографии и rich text выключены.
- **Проверка до записи** — синтаксис JSON и схема. Ошибка показывается сообщением `.form-message` красным с `i-warning-fill`: «<первая проблема> (и ещё N)». «Сохранить» при этом неактивна.
- **Файл изменился**, пока лист открыт, — сообщение оранжевым «Файл изменился, пока он был открыт (например, переключили модель в настройках). Нажмите «Перечитать» и внесите правку заново.» и кнопка «Перечитать».
- **Без ошибок** — «Изменения подхватываются со следующего прохода, переустанавливать не нужно.»
- **Кнопки:**
  - «Открыть в VS Code» — подсказка «Открыть файл во внешнем редакторе; несохранённые правки здесь пропадут», закрывает лист;
  - «Сохранить» — основная, ⌘S или Ctrl+S, неактивна без изменений.

  - исключения;
