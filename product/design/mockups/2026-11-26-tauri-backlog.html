одобрено 26.11.2026 26.11.2026 · дизайнер · задача B-30, экран 6 из 8

Вкладка «Бэклог» переносится из SwiftUI без изменений. Сверху переключатель «Ждут разбора / Все», «Разобрать» и «Скопировать .md». Ниже баннеры задачи, ошибки и «Похоже, неактуальны». Записи сгруппированы по репозиториям: уровень, заголовок, где нашли, действия «Задача заведена» и «Отклонить». Клик по записи раскрывает файл, сценарий, исправление, разбор по коду и источники. Вёрстка — HTML/CSS на product/design/web.

Что меняется по сравнению с SwiftUI. (1) Баннер идущей задачи — обычный .banner--info: в SwiftUI у него была заливка 8 % вместо 10 %. Разницу не видно, а компонент один. (2) Подтверждение разбора — системный диалог. (3) Иконки — Phosphor: «Разобрать» — стетоскоп, как в SwiftUI. (4) В пустом состоянии строки текста выровнены по длине. Под «Всё разобрано» осталась только дата последнего сбора и сколько найдено, без «Повторный запуск разберёт только новые обсуждения». Обе правки — по решению пользователя. Больше ничего не меняется, тексты слово в слово. Заглушка «Бэклог» из первой поставки убирается.

1. Ждут разбора

Первая запись раскрыта: разбор по коду считает её решённой, поэтому вместо «Отклонить» — «Закрыть». У второй открыто поле номера задачи.

Под курсором строка подсвечивается. «Задача заведена» открывает поле «Номер задачи, например PROJ-1234», Enter сохраняет. «Отклонить» открывает поле «Причина, необязательно» с красной кнопкой «Отклонить». «Закрыть» отклоняет сразу, с причиной из разбора. Пока запрос идёт, вместо кнопок крутится индикатор. Номер PR открывает PR в Bitbucket, путь к файлу — файл на коммите, где нашли проблему.

3. Все записи
