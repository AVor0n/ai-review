Журнал в приложении Tauri

одобрено 26.11.2026 26.11.2026 · дизайнер · задача B-30, экран 8 из 8

Вкладка «Журнал» переносится из SwiftUI без изменений: переключатель «Все записи / Ошибки», «Открыть файл» и последние 300 записей журнала сервиса. Свежие сверху. У каждой записи — время и текст моноширинным, у ошибок — оранжевый треугольник и подложка. Длинные записи свёрнуты до двух строк и раскрываются шевроном. Вёрстка — HTML/CSS на product/design/web.

Что меняется по сравнению с SwiftUI. (1) Журнал приходит из API сервиса, а не читается из файла: на Windows файл лежит в WSL. (2) «Открыть файл» на Mac открывает ~/Library/Logs/pr-reviewer/worker.log, как раньше. На Windows — ~/.local/state/pr-reviewer/worker.log из WSL по пути \\wsl.localhost\… в программе по умолчанию. (3) Иконки — Phosphor. Больше ничего не меняется. Заглушка «Журнал» из первой поставки и кнопки «Журнал» в баннерах ведут сюда.
