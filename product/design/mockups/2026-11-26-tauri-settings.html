Вкладка «Настройки» переносится из SwiftUI без изменений. Разделы: «Общие» (тема, фоновое ревью, интервал, уведомления), «Подключённые репозитории», «Модели» с лимитами и выбором модели, «Дополнительно» (ветки, исключения, токены, config.json) и строка сборки. Шесть листов: уведомления, токены, ветки для ревью, новый репозиторий, исключения из диффа, редактор config.json. Лист памяти уже сделан (B-32). Вёрстка — HTML/CSS на product/design/web.

Что меняется по сравнению с SwiftUI.
  1. Переключатели, выпадающие списки и степпер — свои компоненты в стиле листа: .switch, .select, .stepper. Списки и меню «…» у репозитория открывают системное меню, как фильтры статистики.
  2. Листы — поверх поповера, как остальные. Подтверждение «Отключить репозиторий?» — системный диалог.
  3. Токены без слова «Keychain», как в баннере поповера. «Нет в Keychain (…)» → «Не сохранён», в сноске «от даты сохранения в Keychain» → «от даты сохранения».
  4. Windows:
    • «Показать служебную копию в Finder» → «в Проводнике», путь в WSL;
    • «macOS запретила уведомления» → «Windows запретила уведомления», «Открыть системные настройки» → «Открыть параметры уведомлений»;
    • команда сохранения токена — pr-reviewer secret set <id> для терминала Ubuntu вместо security add-generic-password;
    • «Открыть в VS Code» открывает config.json по пути \\wsl.localhost\…, без VS Code кнопки нет;
    • в редакторе config.json Сохранить — Ctrl+S.
  5. Иконки — Phosphor.
Больше ничего не меняется, тексты слово в слово. Заглушка «Настройки» из первой поставки убирается.

2. Листы

Уведомления и свои уведомления репозитория

Репозиторий открывается внутри листа, без второго листа поверх. «‹ Уведомления» возвращает назад. «Уровень» показывается под «Замечаниями моделей», только когда они включены. Если система запретила уведомления, сверху карточка «macOS запретила уведомления PR Reviewer» оранжевым с «Открыть системные настройки». Пока уведомления выключены на время, вместо «Выключить…» — «Выключены до 16:00» оранжевым и «Включить».

Токены · ветки для ревью

«Скопировать команду сохранения» и «Скопировать «claude setup-token»» на время меняются на «Скопировано». Неверное выражение в шаблоне веток — красный треугольник в поле, список показывает совпадения последнего верного шаблона и приглушён до 50 %, «Сохранить» неактивна.

Новый репозиторий · исключения из диффа

В новом репозитории ошибка — текст сервиса красным. Пока сервис проверяет доступ, слева внизу индикатор и «Проверяю доступ…», «Добавить» неактивна. Enter добавляет. В исключениях Enter в нижнем поле добавляет шаблон, красный минус — «Снова отдавать моделям».

config.json

Подсветка JSON:

  • ключи основным цветом;
  • строки и null вторичным;
  • числа синим --code-number;
  • true/false янтарным --code-boolean;
  • скобки и запятые третичным.
Автозамена кавычек и тире выключена. Под редактором — описание поля под курсором из схемы. Ошибка синтаксиса или схемы — красным, «Сохранить» неактивна. Если файл изменился, пока был открыт, — оранжевое сообщение и кнопка «Перечитать».
