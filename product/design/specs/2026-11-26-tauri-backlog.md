# Спецификация: вкладка «Бэклог» в приложении Tauri (B-30, экран 6 из 8)

Дата: 26.11.2026, дизайнер. Одобрено пользователем 26.11.2026 («Одобряю»).

Правки пользователя, внесены в макет:
- в пустом состоянии строки текста одной длины;
- под «Всё разобрано» нет фразы «Повторный запуск разберёт только новые обсуждения».

Макет: `product/design/mockups/2026-11-26-tauri-backlog.html`.
Источник поведения: `menubar/BacklogView.swift` (`BacklogView`, `BacklogRow`), заголовки разбора — `menubar/Model.swift` (`BacklogTriage.title`, `BacklogJob.title`).

## Главное

Вкладка поповера (не лист) переносится без изменений:
- переключатель «Ждут разбора / Все»;
- «Разобрать» и «Скопировать .md»;
- баннеры задачи, ошибки и «Похоже, неактуальны»;
- записи по репозиториям с раскрытием, разбором по коду и полем номера задачи или причины;
- пустые состояния;
- подтверждение разбора.

Тексты — из SwiftUI, кроме двух правок пользователя. Действия — те же команды через API сервиса:
- `backlog filed|drop|reopen`;
- закрыть неактуальные;
- задачи `triage` и `learn`, их остановка;
- экспорт в markdown.

Разметка — шаблоны `tpl-backlog*`, `tpl-row-*`, `tpl-toolbar-waiting` макета. Новое в `product/design/web`:
- классы `.toolbar`, `.link-button--icon`, `.link-button--secondary`, `.banner--success`, `.empty-state__note`, `.backlog-row*`, `.triage-block*`, `.inline-editor`, `.row-divider--backlog`;
- иконки `i-triage` (стетоскоп), `i-x-circle`, `i-warning-circle`.

`.empty-state__text` и `.empty-state__note` теперь с `text-wrap: balance`. Это касается всех пустых состояний и заглушек — так задумано.

## Что меняется по сравнению с SwiftUI

1. Баннер идущей задачи — обычный `.banner--info` (10 %), а не 8 %.
2. Подтверждение разбора — системный диалог Tauri: «Разобрать N записей по текущему коду?», текст из SwiftUI, кнопки «Отмена» и «Разобрать».
3. Пустое состояние:
   - строки выровнены по длине;
   - строка о последнем сборе — «Последний разбор истории — <дата>, найдено N» или «…, ничего не найдено», без хвоста про повторный запуск.
4. Иконки — Phosphor. Заглушка «Бэклог» из первой поставки убирается.

## Ряд над списком (`.toolbar`)

- **Сегменты.** «Ждут разбора / Все», 110 px. Выбор запоминается между запусками (ключ `backlogShowAll`).
- **«Разобрать».** `i-triage`, `.link-button--icon`. Видна, только если есть ждущие разбора записи и задача не идёт. Подсказка: «Проверить по текущему коду основной ветки, какие проблемы ещё актуальны». Открывает подтверждение.
- **«Скопировать .md».** `i-copy`. После копирования на 1,5 с — «Скопировано» с `i-check`. Без записей неактивна. Подсказка зависит от режима:
  - «Ждущие разбора проблемы в markdown…»;
  - «Весь бэклог в markdown…».

## Баннеры

Над списком, по порядку:

| Баннер | Вид | Содержимое |
|---|---|---|
| Ошибка команды | `.banner--alert`, `i-warning-fill` | «Не удалось выполнить команду», текст ошибки в две строки, крестик |
| Задача идёт | `.banner--info`, `.spinner` | «<Разбор по коду / Сбор из истории PR> · <активность или «запуск…»>» вторичным, одна строка, многоточие посередине; справа «Прервать» красным |
| Задача закончилась | `.banner--success` / `.banner--alert` при ошибке | «<название> · 3 минуты назад», текст итога или ошибки (по умолчанию «задача прервана»), крестик |
| Похоже, неактуальны: N | `.banner--info`, `i-triage` | текст из SwiftUI, справа «Закрыть все» |

Итог задачи висит, пока его не закроют. Закрытый запоминается по времени окончания задачи (ключ `backlogJobSeen`).

## Список

**Группы.** Записи сгруппированы по репозиториям в порядке обзора. Отключённые репозитории с записями — в конце. Заголовок группы — «slug · N». Внутри группы:
- в «Все» сначала открытые;
- дальше по приоритету, как `BacklogItem.byPriority`.

Разделители — с отступом 56.

**Строка `.backlog-row`:**
- шеврон, тег уровня (`--level-pN`, колонка 28), заголовок 13 — до двух строк, в раскрытом виде целиком. Клик по этой части раскрывает строку (анимация 150 мс). Подсказка: «Показать сценарий и исправление» / «Свернуть»;
- справа действия, `.link-button` 12 medium:
  - открытая запись — «Задача заведена» акцентным и «Отклонить» вторичным;
  - если разбор по коду считает запись неактуальной — «Закрыть» вместо «Отклонить»: отклоняет сразу с причиной «Неактуально (<вердикт>): <причина>»;
  - разобранная запись — тег «Задача PROJ-…» / «Задача заведена» зелёным или «Отклонено» серым и «Вернуть» (подсказка «Снова в «Ждут разбора»»);
  - пока запрос идёт — `.spinner` вместо действий;
- мета (отступ 56, 11, вторичным):
  - «найдено в #PR #PR · модели и авторы»; номера PR — ссылки на PR;
  - тег «редкий случай» / «гонка или сбой»;
  - тег вердикта разбора, кроме «актуально»: «решено», «удалено», «не баг» зелёным, если запись можно закрыть, иначе серым. Подсказка — причина;
- под курсором фон `--hover`;
- в «Все» разобранные записи — `.backlog-row--closed`: 55 %, под курсором 100 %.

**Раскрытая запись** (отступ 56):
- «Файл» — ссылка моноширинным: открывает файл в Bitbucket на коммите, где нашли проблему. Если ссылку не собрать — серым и неактивна;
- «Сценарий» и «Исправление» — Markdown;
- «Причина отклонения» — у отклонённых;
- `.triage-block` — линия слева и заголовок «<Вердикт> · разбор по коду · 2 часа назад · <ветка> <коммит>»:
  - зелёные, если запись можно закрыть, иначе вторичные;
  - значки: решено `i-check-circle`, удалено `i-trash`, не баг `i-x-circle`, актуально `i-warning-circle`, неясно `i-question`;
- «Где нашли» — по строке на источник: «#PR · кто · как нашли · когда», формулировки из SwiftUI;
- «id … · в бэклоге с …» — 10, третичным, выделяется.

**Поле в строке `.inline-editor`:**
- «Задача заведена» — подсказка поля «Номер задачи, например PROJ-1234», кнопки «Отмена» и «Сохранить» (акцентная);
- «Отклонить» — «Причина, необязательно», кнопки «Отмена» и «Отклонить» (красная);
- поле получает фокус сразу, Enter отправляет.

## Пустые состояния

| Условие | Иконка | Заголовок |
|---|---|---|
| Бэклог пуст | `i-tray` | «Бэклог пуст» |
| В выбранном режиме записей нет | `i-check-circle` | «Всё разобрано» |

Текст — «Сюда попадают проблемы, которые модели нашли по ходу ревью, но которые были в коде ещё до PR».

Если ждущих разбора записей нет:
- строка о последнем сборе (`.empty-state__note`), если сбор был;
- кнопка «Собрать из истории PR». Подсказка из SwiftUI. Пока сбор идёт — `.spinner` вместо кнопки.

## Windows

Рамка поповера из первой поставки, вкладка та же. Проверить:
- длинные заголовки записей обрезаются на второй строке многоточием;
- мета в одну строку не вылезает за карточку.

## Готово, когда

- Вкладка на Mac в светлой и тёмной теме совпадает с макетом, на Windows — то же содержимое. Проверка — скриншот рядом со страницей макета.
- На реальном сервисе работают:
  - оба режима;
  - раскрытие;
  - «Задача заведена» с номером;
  - отклонение с причиной;
  - «Закрыть» по разбору и «Закрыть все»;
  - «Вернуть»;
  - разбор по коду и сбор из истории с ходом, итогом и «Прервать»;
  - копирование markdown;
  - пустые состояния.
- Сегмент «Бэклог» открывает вкладку вместо заглушки.
