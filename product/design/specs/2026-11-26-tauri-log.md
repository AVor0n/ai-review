# Спецификация: вкладка «Журнал» в приложении Tauri (B-30, экран 8 из 8)

Дата: 26.11.2026, дизайнер. Одобрено пользователем 26.11.2026 («Одобряю»).
Макет: `product/design/mockups/2026-11-26-tauri-log.html`.
Источник поведения: `menubar/LogView.swift` (`LogView`, `LogRow`).

## Главное

Вкладка переносится без изменений:
- переключатель «Все записи / Ошибки»;
- «Открыть файл»;
- последние 300 записей журнала сервиса, свежие сверху.

Разметка — шаблоны `tpl-log*` и `tpl-row-*` макета. Классы `.log-row*` и `.row-divider--log` уже в `product/design/web/components.css`, они попали в main с 9cb5194. Ряд сверху — `.toolbar` из бэклога, пустые состояния — `.empty-state`.

## Что меняется по сравнению с SwiftUI

1. Записи приходят из API сервиса (`GET /log`), а не читаются из файла.
2. «Открыть файл» открывает файл журнала в программе по умолчанию:
   - Mac — `~/Library/Logs/pr-reviewer/worker.log`, как раньше;
   - Windows — `~/.local/state/pr-reviewer/worker.log` из WSL по пути `\\wsl.localhost\<дистрибутив>\…`.

   Подсказка — путь к файлу.
3. Иконки — Phosphor.

Заглушка «Журнал» из первой поставки убирается. Кнопки «Журнал» в баннерах поповера ведут на эту вкладку.

## Ряд сверху

- Сегменты «Все записи / Ошибки», 100 px. Выбор запоминается между запусками (ключ `logErrorsOnly`).
- Справа `.link-button--icon` с `i-open-external` и текстом «Открыть файл».

## Записи

Карточка со строками `.log-row`, разделители с отступом 28.

- **Метка слева, колонка 12:**
  - обычная запись — серая точка 4 px;
  - ошибка — `i-warning-fill` 11 px оранжевым, у строки `.log-row--error`: подложка оранжевая 6 %.
- **Время** — «26 нояб. 14:05:12», 10 px, цифры моноширинные, вторичным цветом.
- **Текст** — моноширинный 11:
  - обычная запись — основной цвет на 85 %;
  - ошибка — основной цвет;
  - текст выделяется.
- **Длинные записи.** Многострочная или длиннее 140 символов — свёрнута до двух строк. Справа шеврон `.log-row__toggle` с `i-chevron-down`:
  - в раскрытом виде `.log-row--expanded` — шеврон повёрнут на 180°;
  - подсказка «Показать целиком» / «Свернуть».

Раскрытые записи помнятся, пока открыта вкладка.

## Пустые состояния

| Режим | Иконка | Заголовок |
|---|---|---|
| Все записи | `i-file-text` | «Лог пуст» |
| Ошибки | `i-check-circle` | «Ошибок нет» |

## Windows

Рамка поповера из первой поставки. Проверить:
- длинные строки без пробелов (пути, ветки) переносятся, а не вылезают за карточку — в классе стоит `word-break: break-word`;
- файл из WSL открывается.

## Готово, когда

- Вкладка на Mac в светлой и тёмной теме совпадает с макетом, на Windows — то же содержимое. Проверка — скриншот рядом со страницей макета.
- На реальном сервисе работают:
  - оба режима;
  - раскрытие длинных записей;
  - «Открыть файл»;
  - пустые состояния;
  - новые записи появляются без перезапуска — через SSE или опрос, как в поповере.
- Сегмент «Журнал» и кнопки «Журнал» в баннерах открывают вкладку вместо заглушки.
