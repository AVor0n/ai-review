# Спецификация: меню по правому клику на значке в строке меню

Дата: 30.10.2026, дизайнер. Одобрено пользователем 30.10.2026 («Идея про меню выглядит разумной, давай сделаем»). Бывший пункт A1a аудита.

## Зачем

Частые действия — запустить проход, прервать ревью, выключить фоновое ревью — сейчас требуют открыть поповер. Меню даёт их в два клика и сразу показывает, чем занят сервис.

## Где

`menubar/main.swift`, `rebuildMenu()` (строки 55–76). Меню и сейчас собирается заново при каждом показе, это сохраняем. Комментарий над `rebuildMenu()` («только быстрое выключение уведомлений и выход») обновить.

## Состав меню

```
  Идёт ревью: frontend #2828 · Claude (первым)     ← строка статуса, серая
  ─────────────────────────────
  Проверить сейчас              ← или «Прервать ревью», см. ниже
  Выключить фоновое ревью       ← или «Включить фоновое ревью»
  ─────────────────────────────
  (Уведомления: …)              ← как сейчас, только когда выключены
  (Включить уведомления)
  Выключить уведомления  ›
  ─────────────────────────────
  Выйти из PR Reviewer      ⌘Q
```

Блок уведомлений и «Выйти» остаются без изменений.

## Строка статуса

Обычный `NSMenuItem` с `action: nil`, поэтому macOS рисует его серым и не даёт кликнуть. Он один и стоит первым. Текст выбирается в том же порядке, что подсказка значка в `refreshIcon()`:

| Состояние | Текст |
|---|---|
| Проход завис | Проход не продвигается N мин |
| Идёт ревью | Идёт ревью: frontend #2828 · Claude (первым) — то же, что даёт `currentText()` |
| Идёт доработка | Идёт доработка · Claude |
| Фоновое ревью выключено | Фоновое ревью выключено |
| Последний проход с ошибкой | Последний проход завершился с ошибкой |
| Ожидание | Следующий проход через N мин; если осталась минута или меньше — «Следующий проход в течение минуты» |

Если время следующего прохода неизвестно, пишем просто «Ожидание».

## Действия

Набор повторяет кнопки в шапке обзора (`OverviewView.swift:105–130`):

| Состояние | Первый пункт | Что делает |
|---|---|---|
| Идёт ревью или проход завис | Прервать ревью | `stop`, как кнопка ■ в шапке обзора |
| Ожидание или ошибка, фоновое ревью включено | Проверить сейчас | `run-now`, как кнопка ▶ |
| Фоновое ревью выключено | — (пункта нет) | |

Второй пункт — переключатель фонового ревью:
- «Выключить фоновое ревью», когда оно включено — `pause`;
- «Включить фоновое ревью», когда выключено — `resume`.

Это тот же общий переключатель, что вверху «Настроек». Подтверждения не нужно: в настройках его тоже нет. Выключение прерывает идущее ревью, как и в настройках.

Доработку, архитектурное ревью и тестирование из меню не прерываем: у каждого из них своя кнопка в строке PR.

После действия обновить значок (`refreshIcon()`), как это уже делают пункты уведомлений. Открытый поповер подхватит новое состояние сам при следующем `reload()`.

## Тексты

Тексты сверены со словарём терминов (`product/design/terms.md`):
- «фоновое ревью выключено», а не «пауза»;
- «проход» — один запуск по всем репозиториям;
- «Проверить сейчас» — тот же глагол, что в подсказке ▶.

В макете, показанном пользователю, был пункт «Приостановить фоновое ревью». По словарю он заменён на «Выключить фоновое ревью».

Строки меню пишутся без точки и без многоточия: ни один пункт не открывает окно.

## Проверка

По коду, без проверки на экране (решение пользователя: на экране проверяем только сложные задачи). Нужно сверить:
- в каждом состоянии из таблиц нужный набор пунктов;
- «Прервать ревью» и «Проверить сейчас» никогда не стоят в меню вместе;
- на выключенном фоновом ревью нет ни одного из них.
