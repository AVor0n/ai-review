## Замечания

1. **Старый пункт входа macOS запускает приложение второй раз при каждом входе.**
   - В «Объектах входа» пользователя остался пункт «PR Reviewer» с путём `~/Applications/PR Reviewer.app`. В фоновых задачах macOS он записан под bundle id окна SwiftUI.
   - Раньше по нему стартовало окно SwiftUI. Теперь по этому пути лежит приложение Tauri, и при входе его запускают двое: этот пункт и новый агент `…tray`.
   - Второй запуск не стартует, а через single-instance переключает поповер. Так он открылся у меня, когда я запускал бинарник повторно. Значит, при входе поповер, скорее всего, сам откроется на экране.
   - Ни `install.sh`, ни `uninstall.sh` этот пункт не трогают.
   - Исправление: убирать пункт входа с этим путём при установке и удалении. Например, `osascript -e 'tell application "System Events" to delete login item "PR Reviewer"'` с проверкой пути.
   - Вход в систему не проверялся; вывод — по списку объектов входа и поведению второго запуска. S3.
2. **В `assets/` остались файлы окна SwiftUI.** `AppIcon.icns`, `make-icon.swift`, `make-tray-icons.swift` нигде не используются: значки Tauri лежат в `app/src-tauri/icons`. Можно удалить. S4.

- **Автозапуск после выхода из системы и входа.**
- **Windows** — после #53.
