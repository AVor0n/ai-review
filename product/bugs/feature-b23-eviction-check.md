## Замечания

- **Склонение в общей причине** — BUG-031, исправлен в 2810b47. Строка «память заполнена (${limit} правил)» склоняется неверно при лимите вроде 3 или 61: «3 правил», «61 правил». При лимите 60, который стоит по умолчанию и сейчас в конфиге, всё верно. Строка была и до B-23.
- **Вытеснено правило, которое смягчает замечания.** Оно велит задавать короткий вопрос вместо ошибки. Все три отклонённых замечания с ним — уровня P2 и помечены `disputed`, два из трёх из одного PR (#2058). Похоже, люди отклоняли и смягчённые вопросы. Без правила ревьюер может снова писать об этом как об ошибке, то есть громче. Вопрос к PM: годится ли «отклоняли чаще, чем исправляли» для правил, которые смягчают или запрещают замечания.
- **Баннер при переполнении без вытеснения** — BUG-032, исправлен в 1ced8dd. При 61 из 60 баннер «Память заполнена» по-прежнему пишет «Новые правила вытесняют наименее полезные автоматические». На деле вытеснять нечего и память растёт. Проверено по коду: условие `count >= memoryLimit`, а текст один.
