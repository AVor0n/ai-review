# BUG-023: у записей бэклога без файла печатается «null»

- **Статус:** закрыт
- **Серьёзность:** S4
- **Компонент:** CLI (`src/backlog.mjs`, `src/cli.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** техпод при написании docs/, подтверждено qa по коду и данным

## Описание

Если у записи бэклога нет `path`, «null» выводится в `backlog list`, в `backlog export` и в `.pr-review/backlog.md`, который получает модель (``- `null` — заголовок``).

## Окружение

- В `backlog.json` 33 записи, у одной нет `path`.

## Шаги воспроизведения

1. `bin/pr-reviewer backlog list --all` (только чтение).

## Фактический результат

`… · null · PR #…`

## Ожидаемый результат

Место не показывается или заменяется на «без файла».
