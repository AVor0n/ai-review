# BUG-010: устаревшие и неточные тексты в окне и промпте памяти

- **Статус:** передан dev (тексты — согласовать с designer)
- **Серьёзность:** S4
- **Компонент:** окно (`menubar/*.swift`), CLI (`src/memory.mjs`, `src/review.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** сверка README с кодом (техпод), подтверждено qa по коду

## Описание

Несколько текстов расходятся с поведением.

1. **Зависание прохода.** Баннер: «В журнале нет записей с …: похоже, завис git или модель». Уведомление: «Нет записей в журнале N мин». Зависание определяется по `heartbeat`, а не по журналу, и модель пульс не останавливает (`menubar/Model.swift:974-982`, комментарий там же). Корректно: «Сервис N мин не подаёт признаков жизни, последняя запись в журнале — HH:MM; похоже, завис git или сеть».
   - `menubar/OverviewView.swift:305`, `menubar/Alerts.swift:229`
2. **Подсказка кнопки ▶:** «не дожидаясь 15 минут». Интервал настраивается, в конфиге сейчас 5.
   - `menubar/OverviewView.swift:144`
3. **«Нет в диффе — строки замечания нет в изменениях PR».** На деле `dropped` — это когда нет файла в диффе (или в нём нет строк нужной стороны). Замечание к строке вне диффа привязывается к ближайшей (`src/diff.mjs:60-79`). Та же неточность в логе: «строки … нет в диффе, замечание пропущено».
   - `menubar/StatsView.swift:392`, `src/review.mjs:163`
4. **«Обеих моделей» при трёх моделях:**
   - `menubar/StatsView.swift:196` — «Замечаний обеих моделей на 1000 изменённых строк»
   - `menubar/SettingsView.swift:1132` — «учитываются … обеими моделями»
   - `src/memory.mjs:152` — промпт памяти: «Две модели (Claude и Codex) оставляют замечания». Это уже влияет на модель: замечания Cursor в обсуждениях она может не узнать как замечания модели. Список лучше брать из `config.agents`.

## Ожидаемый результат

Тексты соответствуют поведению; список моделей не зашит в текст.
