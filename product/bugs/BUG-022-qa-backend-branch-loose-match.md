# BUG-022: тестирование подбирает ветку бэкенда по слишком широкому шаблону

- **Статус:** отложен
- **Серьёзность:** S4
- **Компонент:** CLI (`src/qa.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** техпод при написании docs/, подтверждено qa по коду

## Описание

Ветка бэкенда той же задачи ищется по шаблону `(^|[^0-9])(PROJ-)?<номер>($|[^0-9])`. Под него попадает любая ветка, где номер стоит между нецифровыми символами: при задаче 123 подходят и `release/1.123`, и `hotfix/v2.123`. Если совпадений два и больше, молча берётся `develop`, хотя ветка задачи есть. В журнале и отчёте видно только «Сборка бэкенда из origin/develop», без причины.

## Шаги воспроизведения

Изолированная проверка шаблона на задаче 123: `PROJ-123-x` и `123` — совпадение (верно); `release/1.123` и `feature/v0.123` — тоже совпадение (ложное).

## Ожидаемый результат

Совпадение только с веткой задачи (`PROJ-123…` или ровно `123`). При неоднозначности — предупреждение в шагах прогона.
