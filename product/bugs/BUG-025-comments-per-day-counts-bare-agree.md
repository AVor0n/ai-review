# BUG-025: «Комментарии по дням» считают согласия, которые не публикуются

- **Статус:** закрыт
- **Серьёзность:** S4
- **Компонент:** окно (`menubar/Model.swift`, `menubar/StatsData.swift`)
- **Заведён:** 2026-10-30, qa
- **Источник:** техпод при написании docs/, подтверждено qa по коду

## Описание

`postedComments` = замечания + все вердикты, кроме `skip`. Но ответ без текста (голое «согласен») отдельным комментарием не публикуется: в чужое замечание дописывается только отметка «✓ … проверил и согласен» (`src/review.mjs:204-209`). График «Комментарии по дням» завышает число опубликованных комментариев на число таких согласий.

## Ожидаемый результат

Считаются только реально опубликованные ответы. Для этого в `stats.jsonl` нужен признак, был ли у ответа текст (или число опубликованных ответов).

## Предполагаемое место в коде

- `menubar/Model.swift:64-66`, `menubar/StatsData.swift:296`
- `src/review.mjs:197` — в `verdicts` не пишется, опубликован ли ответ.
