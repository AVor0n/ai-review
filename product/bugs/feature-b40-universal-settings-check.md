## Замечания

1. **Старый образ Docker остаётся на диске.** Образ бэкенда для тестирования теперь называется `pr-reviewer-qa-backend`, раньше назывался по имени клиента. Старый образ (590 МБ) на Mac пользователя остался, а очистка смотрит только образы с новым именем — он не удалится никогда. Первый прогон после обновления соберёт образ заново, это лишние минуты один раз. Контейнеров и томов со старым именем проекта нет. Можно удалить старый образ при переносе или один раз руками. S4.
2. **SwiftUI-приложение всё ещё со своими значениями по умолчанию.** Условие проверки «`git grep` пусто» не выполнено из-за `menubar/*.swift`. На пользователя это не влияет: перенос дописал `qa` и `displayPrefix` в живой конфиг. Но у нового пользователя SwiftUI будет считать ветки по ключу клиента и показывать тестирование для чужого репозитория. Если SwiftUI уходит на этапе 4 — можно оставить до него. S4.

Не проверено:
- **Docker с новыми именами.** Прогон тестирования не запускался.
- **Настоящий Tauri и Windows.**

Заметка о копии: при проверке «Статистика» роняла интерфейс целиком — из-за трёх записей `stats.jsonl`, которые я дописал руками при проверке #42 без поля `verdicts`. Сервис такие записи не пишет, в живом файле их нет; записи из копии убраны.
