# BUG-012: в «Журнале» раскрытая запись перескакивает на другую

- **Статус:** передан dev
- **Серьёзность:** S4
- **Компонент:** окно (`menubar/Model.swift`, `menubar/LogView.swift`)
- **Заведён:** 2026-10-30, qa
- **Источник:** сверка README с кодом (техпод), подтверждено qa по коду

## Описание

Окно читает последние 256 КБ лога, и id записи — её порядковый номер в этом хвосте (`LogEntry(id: entries.count…)`). Раскрытые записи запоминаются по id. Когда лог больше 256 КБ (сейчас 332 КБ), каждая новая запись сдвигает начало хвоста, номера съезжают, и раскрытой оказывается другая запись. Раскрытие ошибок со стеком в «Журнале» при идущем ревью сбивается.

## Окружение

- `worker.log` — 332 КБ, лимит хвоста — 256 КБ.

## Шаги воспроизведения

1. «Журнал», раскрыть многострочную запись (ошибку со стеком).
2. Дождаться новой записи в логе (идёт ревью).

## Фактический результат

Раскрыта другая запись, нужная свернулась.

## Ожидаемый результат

Раскрытая запись остаётся раскрытой.
