# BUG-007: прерванный план тестирования показывается как «Прогон не удался»

- **Статус:** закрыт
- **Серьёзность:** S4
- **Компонент:** CLI (`src/qa.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** сверка README с кодом (техпод), подтверждено qa по коду

## Описание

`abort` в обработчике тестирования всегда пишет `state: 'failed'`, даже когда шёл план. Обычная ошибка плана пишет `plan-failed`. В окне `failed` значит «Прогон не удался: тестирование прервано», и лист открывается на вкладке «Отчёт» (`menubar/QaViews.swift:129, 167, 195`), хотя прогона не было.

## Шаги воспроизведения

С разрешения пользователя (трата на модель):

1. `qa plan --repo frontend --pr <id>`.
2. Пока план составляется — `qa stop`.
3. Посмотреть пробирку и лист в окне, `qa list`.

## Фактический результат

«Прогон не удался: тестирование прервано», лист на вкладке «Отчёт».

## Ожидаемый результат

«План тестирования не удался: план прерван», лист на вкладке «План».

## Предполагаемое место в коде

- `src/qa.mjs:678` — выбирать `plan-failed`, если `current.stage === 'plan'` (как в `src/qa.mjs:748`).

- 2026-10-30 — пользователь подтвердил баг и оставил правку 57f0012 (со слов dev)
- 2026-10-30 — qa: по коду `abort` при `stage: plan` пишет `plan-failed` и «план прерван»; окно для `plan-failed` показывает «План тестирования не удался: план прерван» и переключает лист на «План» (`menubar/QaViews.swift:126, 196`), `qa list` — «план не удался». Живым прерыванием не проверял (тратит модель). Закрыт
