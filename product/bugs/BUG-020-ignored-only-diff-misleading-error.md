# BUG-020: архитектура и тестирование падают с «в PR нет изменений», когда все изменения в исключениях

- **Статус:** закрыт
- **Серьёзность:** S4
- **Компонент:** CLI (`src/arch.mjs`, `src/qa.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** техпод при написании docs/, подтверждено qa по коду

## Описание

Архитектурное ревью и план тестирования строят дифф без файлов из `ignorePaths`, и если он пустой, падают с ошибкой «в PR нет изменений относительно целевой ветки». Но изменения есть, просто все в исключённых файлах (lock-файлы, снапшоты). Обычное ревью эти случаи различает: «в диффе только исключённые файлы» (`src/review.mjs`, `reason: 'ignored'`).

## Шаги воспроизведения

С разрешения пользователя: архитектурное ревью PR, который меняет только `yarn.lock`.

## Фактический результат

Треугольник: «Архитектурное ревью не удалось: в PR нет изменений относительно целевой ветки».

## Ожидаемый результат

«В PR изменены только исключённые файлы (ignorePaths) — разбирать нечего».
