## Замечания

1. **Нажатие на уведомление ничего не открывает, хотя лист обещает обратное.** В сноске листа: «Нажатие на уведомление открывает PR или тред.» В SwiftUI у уведомления есть ссылка, по нажатию открывается PR, комментарий или тред. В Tauri `notify(title, body)` шлёт уведомление без ссылки и без обработчика нажатия. Видно по коду (`notify.ts`, `lib.rs`); на копии уведомления подменены. Нужно либо открывать ссылку по нажатию, либо убрать фразу из сноски. S3.
2. **После подключения репозиторий не скачивается.** В SwiftUI `addRepo` сразу запускает `repo clone`. Так задумано и в CLI: «окно настроек скачивает отдельной командой `repo clone`». В Tauri после `POST /repos` нет `POST /repos/{slug}/clone`, у нового репозитория остаётся «Скачать». Пока его не нажать, нет клона и списка PR; клон сделает только следующий проход сервиса. S3.
3. **Команда сохранения токена Cursor на Mac создаст вторую запись в Keychain.** Лист собирает команду с `-a cursor` (`account = token.id`). SwiftUI берёт аккаунт существующей записи (`Tokens.swift`: `saved?.account`). У живой записи `pr-reviewer-cursor` аккаунт другой (см. B-28, замечание 1). Скопированная команда добавит вторую запись, а чтение по service может вернуть старую. CLI это исправил в B-28 (`reuseAccount`); здесь нужно брать аккаунт существующей записи. На Windows команда — `pr-reviewer secret set cursor`, там проблемы нет. S3.
4. **Мелкие отличия.** S4.
   - «Ревью завершено»: тело «Замечания P1: 1, P2: 2», в SwiftUI — «Замечания: P1 P2×2».
   - Редактор config.json: ошибка синтаксиса — текстом движка JS по-английски («Expected ',' or '}' after property value…»), в SwiftUI — системное сообщение.
   - Редактор config.json: о чужом изменении файла лист сообщает только после нажатия «Сохранить» (409); SwiftUI показывает сообщение и «Перечитать» сразу, как только файл изменился.

Не проверено:
- **Описание поля под курсором.** На синтетическое перемещение курсора подсказка не сменилась; живым курсором не проверял.
- **Списки моделей Codex и Cursor.** В копии нет кэша Codex CLI, а заглушка `cursor-agent` при открытии вкладки записала пустой список моделей Cursor (только в копии).
- **«Обновить лимиты».** Ходит в сеть; при открытии вкладки вызвался `POST /limits/refresh`.
- **Системные меню, диалоги, уведомления и запрет уведомлений в macOS** — на настоящем Tauri.
