# BUG-011: в листе «Токены» любой модели, кроме Cursor, предлагается `claude setup-token`

- **Статус:** передан dev
- **Серьёзность:** S4
- **Компонент:** окно (`menubar/Tokens.swift`)
- **Заведён:** 2026-10-30, qa
- **Источник:** сверка README с кодом (техпод), подтверждено qa по коду

## Описание

Способ выпуска токена выбирается тернарником: `cursor` — ссылка на дашборд Cursor, всё остальное — `claude setup-token`. Если у Codex (или новой модели) появится `keychainService`, лист предложит выпускать токен командой Claude.

## Окружение

- Сейчас не проявляется: у `agents.codex` нет `keychainService`.

## Ожидаемый результат

Способ выпуска задан для каждой модели явно; для модели без известного способа нет кнопки или команды.
