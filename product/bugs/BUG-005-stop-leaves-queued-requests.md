# BUG-005: `fix stop`, `arch stop`, `qa stop` оставляют заявки в очереди

- **Статус:** закрыт
- **Серьёзность:** S3
- **Компонент:** CLI (`src/fix.mjs`, `src/arch.mjs`, `src/qa.mjs`), окно (`menubar/Model.swift`)
- **Заведён:** 2026-10-30, qa
- **Источник:** сверка README с кодом (техпод), подтверждено qa по коду

## Описание

«Прервать» убивает процесс-обработчик целиком (`process.exit(143)` в `abort`). Текущая задача помечается прерванной, но остальные файлы в `fixes/queue`, `arch/queue`, `qa/queue` остаются, а обработчика больше нет. У этих PR в окне навсегда висят часы «в очереди»: окно переводит в «прервано» только `running`/`planning`. Когда кто-то запросит новую доработку, архитектурное ревью или тестирование, обработчик запустится и выполнит и старые заявки. Это может быть доработка с пушем в чужой PR, которую человек уже считал отменённой.

## Окружение

- Очереди сейчас пусты.

## Шаги воспроизведения

С разрешения пользователя (пуш в ветки PR, траты):

1. Поставить доработку по PR A и сразу по PR B (B ждёт в очереди).
2. Во время доработки A нажать «Прервать» (`fix stop`).
3. Посмотреть `~/Library/Application Support/pr-reviewer/fixes/queue/` и обзор.
4. Через какое-то время поставить доработку по PR C.

## Фактический результат

После шага 2 A — «прервано», B — «в очереди» без движения. После шага 4 выполняются и B, и C.

## Ожидаемый результат

«Прервать» очищает очередь своего вида задач, и у оставшихся заявок состояние меняется на «отменено» или «прервано». Другой вариант: прерывается только текущая задача, а обработчик идёт дальше по очереди. Что из этого задумано — решение PM.

## Решение пользователя (2026-10-30)

«Прервать» у PR отменяет задачу только этого PR — идущую или ждущую в очереди; заявки других PR продолжают выполняться. Это ожидаемый результат для BUG-005 и BUG-017.

## Предполагаемое место в коде

- `src/fix.mjs:54-58`, `src/arch.mjs:61-65`, `src/qa.mjs:96-100` — `stop*` только шлют SIGTERM.
- `src/fix.mjs:372-378`, `src/qa.mjs:675-680` (и аналог в `arch.mjs`) — `abort` не трогает очередь.
- `menubar/Model.swift:1229, 1268, 1314` — `queued` при мёртвом обработчике не считается прерванным.
