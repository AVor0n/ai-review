# BUG-013: `pr-reviewer stats` занижает цену за исправленное замечание

- **Статус:** передан dev
- **Серьёзность:** S4
- **Компонент:** CLI (`src/stats.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** сверка README с кодом (техпод), подтверждено qa по коду

## Описание

Комментарий в `src/stats.mjs:31`: цена считается только по запускам с известной ценой, чтобы не занижать среднее. «За запуск» и «за замечание» так и сделаны (`priced`, `pricedFindings`). Но «за исправленное» делит ту же сумму на все `addressed`, включая замечания из запусков без цены (Codex и Cursor до появления тарифов). Цифра занижена.

## Шаги воспроизведения

1. `bin/pr-reviewer stats` (только чтение).
2. Сравнить «$… за исправленное» с суммой цены запусков, давших исправленные замечания, делённой на их число.

## Фактический результат

Деление на все `addressed`.

## Ожидаемый результат

Знаменатель — исправленные замечания из запусков с ценой (по аналогии с `pricedFindings`).
