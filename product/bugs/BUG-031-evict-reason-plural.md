# BUG-031: «память заполнена (3 правил)» — число правил не склоняется

- **Статус:** закрыт
- **Серьёзность:** S4
- **Компонент:** CLI (`src/memory.mjs`)
- **Заведён:** 2026-11-17, qa
- **Источник:** найдено qa при проверке B-23 (`feature-b23-eviction-check.md`)

## Описание

Общая причина записи `evict` в истории памяти — «память заполнена (${limit} правил)». Слово «правил» не склоняется по лимиту: при лимите 3 будет «3 правил», при 61 — «61 правил», при 1 — «1 правил». Текст показывается в окне на вкладке «Что менялось». При лимите 60 по умолчанию всё верно. Строка была и до B-23.

## Шаги воспроизведения

1. Копия данных, в копии конфига `memory.maxLessons` = 3.
2. Добавить правило в репозиторий, где правил больше трёх.
3. Посмотреть последнюю запись `evict` в `memory/<repo>.history.jsonl`.

## Фактический результат

«память заполнена (3 правил)».

## Ожидаемый результат

«память заполнена (3 правила)», «(61 правило)», «(60 правил)».
