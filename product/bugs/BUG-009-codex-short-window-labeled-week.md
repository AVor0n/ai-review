# BUG-009: короткое окно лимита Codex подписывается как недельное

- **Статус:** отложен
- **Серьёзность:** S4
- **Компонент:** окно (`menubar/SettingsView.swift`)
- **Заведён:** 2026-10-30, qa
- **Источник:** сверка README с кодом (техпод), подтверждено qa по коду

## Описание

CLI пишет `window: 'week'` только для окна от 6 суток, иначе `'window'` (`src/limits.mjs:36`). Окно подписывает всё, что не `month`, как «недели» / «на неделю». Если Codex вернёт короткое окно (например, 5-часовое), будет «N% недели осталось».

## Окружение

- Сейчас не проявляется: в `limits.json` у Codex `window: "week"`.

## Шаги воспроизведения

Проверка на изолированной копии данных: в `limits.json` у codex поставить `"window": "window"` и открыть настройки окна (`HOME=<scratch>`, отдельная сборка, с разрешения пользователя).

## Фактический результат

«N% недели осталось».

## Ожидаемый результат

Подпись по реальному окну («N% лимита осталось · до HH:MM») или длительность окна в данных.

## Предполагаемое место в коде

- `menubar/SettingsView.swift:381, 386`
- `src/limits.mjs:36` — можно отдавать длительность (`limit_window_seconds`), чтобы окно подписывало точно.
