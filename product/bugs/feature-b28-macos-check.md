## Замечания

1. **`secret set cursor` на Mac создаст вторую запись в Keychain.** `secret set` пишет у моделей аккаунт, равный id модели (`-a cursor`). Живая запись `pr-reviewer-cursor` заведена с другим аккаунтом (не `cursor`), поэтому `add-generic-password -U` её не обновит, а добавит вторую. Ключ Cursor читается без аккаунта, по одному service, и `security` вернёт первую подходящую запись — возможно, старую. Новый ключ тогда не подхватится, а `secret status` скажет «есть». У Claude аккаунт в Keychain `claude`, совпадает. Проверено по коду и по атрибутам записей, без записи в Keychain. S3.
   - **Пользователь 25.11: чинить.** Передано dev: на Mac писать с аккаунтом уже существующей записи service. После правки qa проверит на временной записи Keychain.
2. **`secret set` на Mac передаёт значение аргументом `security`**, и на время вызова его видно в списке процессов. Так же было и в командах, которые печатает `install.sh`, — не новое. Только наблюдение.
3. **`data import --force` не очищает папку данных, а докладывает поверх.** Файлы, которых нет в архиве, остаются: старый `state.json` перезапишется, а, например, файлы памяти репозитория, которого нет в архиве, останутся. Для переноса на чистую машину не важно. Только наблюдение.

Не проверено на живой установке, нужно разрешение пользователя: проход воркера, явное и архитектурное ревью, доработка и QA (тратят лимиты и публикуют), `run-now` из окна и CLI, `uninstall.sh`. По коду там только замена вызовов на функции `platform.mjs` с теми же аргументами.
