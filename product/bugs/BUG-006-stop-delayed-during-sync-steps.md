# BUG-006: «Прервать» не срабатывает во время синхронных шагов доработки и тестирования

- **Статус:** передан dev
- **Серьёзность:** S3
- **Компонент:** CLI (`src/fix.mjs`, `src/qa.mjs`)
- **Заведён:** 2026-10-30, qa
- **Источник:** сверка README с кодом (техпод), воспроизведено qa изолированно

## Описание

Обработчик SIGTERM в Node — JS-колбэк, он вызывается только когда свободен цикл событий. Длинные шаги идут через `execFileSync`/`spawnSync`: установка зависимостей (до 20 мин), `lint`/`ts-check`/`test` (до 20 мин на скрипт), `docker build` (до 40 мин), `compose up` (до 20 мин), итоговый Playwright (до 40 мин). Всё это время «Прервать» ничего не делает, а CLI сразу печатает «прервано». Дочерний процесс SIGTERM не получает и доживает до конца шага.

## Окружение

- Node v22.23.1, macOS 27.0.1

## Шаги воспроизведения

Изолированно, без сервиса: `/private/tmp/claude-503/-Users-a-voronin-tools-pr-reviewer/d7bff2a4-1b7c-4bb6-985f-110379b08f1d/scratchpad/sigterm-sync.mjs`. Скрипт вешает обработчик SIGTERM и вызывает `execFileSync('sleep', ['6'])`; SIGTERM ему шлётся через 1 с.

```
sleep закончился через 6.0 с
SIGTERM обработан через 6.0 с
exit=143
```

В живом сервисе — с разрешения пользователя: запустить доработку и нажать «Прервать» на шаге «ставлю зависимости».

## Фактический результат

Прерывание срабатывает только после конца синхронного шага, то есть через минуты, до 40 мин.

## Ожидаемый результат

Прерывание за секунды: дочерний процесс убит, окружение остановлено.

## Предполагаемое место в коде

- `src/fix.mjs:94` (`sh` → `execFileSync`, установка зависимостей), `src/fix.mjs:114` (`spawnSync`, проверки)
- `src/qa.mjs:243` (`docker build`), `src/qa.mjs:251` (`compose up`), `src/qa.mjs:423` (итоговый Playwright)
- `src/fix.mjs:378`, `src/qa.mjs:682` — обработчики SIGTERM
- `src/cli.mjs:302, 458` — CLI сразу сообщает «прервано»

Вариант исправления: асинхронный `spawn` с запоминанием дочерних процессов и их убийством в `abort`, или своя группа процессов и `kill(-pgid)` в `stop*`.
