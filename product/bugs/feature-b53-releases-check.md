## Замечания

1. **Приложение в `.dmg` не подписано совсем, даже ad-hoc.**
   - `codesign --verify` пишет «code object is not signed at all». Подписан только сам бинарник, подписью компоновщика, а у бандла подписи нет.
   - Локальная установка подписывает бандл сама (`codesign --sign -` в `install-macos.zsh`), поэтому живое приложение проходит проверку. В CI этого шага нет.
   - `syspolicy_check distribution` для бандла из релиза даёт фатальную ошибку «File is not signed at all». Для той же копии после `codesign --force --deep --sign -` остаются только предупреждения: «ad-hoc» и «нет нотаризации».
   - Чем грозит: на Mac с Apple Silicon скачанное через браузер неподписанное приложение macOS обычно называет «повреждённым» и предлагает удалить. Кнопки «Всё равно открыть» в «Конфиденциальности и безопасности» тогда нет, и заметки релиза не помогут.
   - Это вывод по подписи, а не по запуску: открыть скачанную копию мне не дали.
   - Исправление: подписывать ad-hoc при сборке, например `"signingIdentity": "-"` в `bundle.macOS` файла `tauri.conf.json`. Проверка в CI: `codesign --verify --deep --strict` по бандлу.
   - S3.
2. **README обещает, что ручной запуск workflow собирает без релиза.**
   - Так только при запуске на ветке. Запуск на теге `app-v*` релиз публикует: так и вышел 0.1.0.
   - Можно уточнить фразу. S4.

Уже известно dev: в README установщик называется `PR Reviewer_…`, а в релизе `PR.Reviewer_…`.
